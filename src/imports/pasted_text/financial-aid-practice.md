Create a simple, polished website called **Financial Aid Practice**.

It is a free **Youth Awareness Network (YAN)** initiative that helps students practice financial aid forms before completing real applications.

### Main idea

Many students struggle with financial aid applications because they do not know beforehand what information, documents, income details, expenses, assets and family information they will need.

This website lets students practice the process in advance.

The attached UWC financial aid form should be used as the main reference for the practice questions and sections. It includes areas such as parents/guardians, family members, income, bank statements, assets, property, taxes, expenses, loans, dependents, education expenses, travel and expected family contribution.

Do not copy UWC branding. This is an independent YAN project.

---

## DESIGN

Use only:

**#292626**
**#FFFFFF**

Use subtle shades of these colors for backgrounds and borders if necessary.

The design should feel:

* Clean
* Minimal
* Professional
* Educational
* Trustworthy
* Human

It should look like a **well-designed WordPress educational platform**, NOT an AI-generated SaaS website.

Avoid:

* Gradients
* Neon colors
* Glassmorphism
* 3D graphics
* AI illustrations
* Excessive rounded cards
* Excessive animations
* Dollar/coin graphics
* Emoji-heavy design

Use clean typography, simple icons, borders and generous spacing.

Make it fully responsive for desktop and mobile.

Each step should have:

* Clear heading
* Short explanation
* Questions
* Back
* Continue
* Save Progress

Do not create one extremely long page.

* Bank statements
* Business documents
* Property documents
* Tax records

# PRIVACY

This platform should not require an account.

Do not create a database for financial information.

Save practice progress locally in the user's browser.

Show:

> "Your practice information stays on this device. Financial Aid Practice does not need an account or server database for the practice form."

Also provide:

**Save Progress**

**Continue Practice**

**Clear My Data**

Do not ask users for passwords, bank account numbers or other unnecessary sensitive information.
